# Axiom 현재 제품 기준선

현재 기준은 [Foundation 1.0.0 전체 문서](foundation/README.md)다. 방향과 56개 문서 인덱스를 확인받아 전체 본문·부록을 작성했고 전체 문서 기준선 확인을 기다린다. [문서 검토 기록](foundation/baseline-review.md)에서 범위와 검증 한계를 확인한다.

이 디렉터리의 이전 architecture/model/research 문서는 작성 당시의 제안·실험 근거다. 이후 변경된 외부 Agent 범위, native 초기 필수, 조건부 토큰 표준, UI 목적 경계의 현재 규칙은 Foundation 본문이 정리한다. 과거 runtime 실험과 deprecated 코드는 새 제품의 구현 완료를 뜻하지 않는다.
