## 확정 범위

확정 대상은 D01–D39의 129개 원 답변, DQ01–DQ14의 보충 해석, 통합 검토본의 RP01–RP09 조합·위임안과 후속 검증의 판정 조건입니다. 이미 선택된 요구를 같은 질문으로 다시 열지 않습니다.

- 첫 제품은 Axiom Studio의 Design System Builder이며 DSF와 컴포넌트 정의를 ADS로 연결합니다.
- 컴포넌트는 범용 UI 목적·값·이벤트·상태·동작·접근성·모션을 표현하고 소비 앱의 비즈니스 규칙과 분리합니다.
- GUI·내장 AI·외부 Agent는 공식 API/MCP와 공통 검증 명령 경로를 사용합니다. 외부 Agent의 제품 사용권에 코어 API·검증기·권한 구현 수정권은 포함하지 않습니다.
- 외부 React 코드 import·역반영·반복 동기화의 초기 제외는 유지합니다.
- 자체 토큰 표준은 동등 이상 기능과 더 적은 전체 트레이드오프가 입증되면 선택할 수 있습니다. 이점이 없으면 DTCG 전체 지원을 기준으로 합니다.
- Web/Mobile 디자인 범주와 출력 기술을 구별하며, 전체 카탈로그와 필수 출력 범위를 임의로 축소하지 않습니다.
- 모션은 keyframe을 포함한 합의된 초기 범위를 유지합니다. 실시간 협업은 초기 구조를 준비하고 구현은 후속입니다.
- 과거 공개 안정 파일은 원본을 보존하고 최신 형식으로 migration하여 계속 편집하는 방식을 선택합니다.
- 공개 코어·기업 Studio 소스·사용자 산출물의 권리를 구별하고 구체 라이선스와 가격은 정한 비교·판정 절차로 선택합니다.

## 이번 확인으로 확정되지 않는 것

자체 표준의 기술 우위, 구체 Canvas/텍스트 엔진·모든 출력 조합의 실제 구현체, 정확한 라이선스·가격·실측 수치가 자동으로 결정되지는 않습니다. 이 항목들은 확인한 조건에 따라 상세화합니다. 검증되지 않은 결과를 구현 완료나 정식 지원으로 표시하지 않습니다.

**Foundation 문서 인덱스 승인, 전체 상세 문서 승인, 새 제품 구현 시작은 아직 별도 단계입니다.** 다음 확인 대상은 [문서 인덱스와 개발 방향](../foundation/README.md)입니다.
