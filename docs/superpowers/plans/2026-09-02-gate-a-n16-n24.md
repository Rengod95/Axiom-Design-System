# Gate A N16-N24 implementation plan

> Execute every production-code step with test-driven development: add the
> focused failing test or normative negative fixture, confirm the intended
> failure, add the minimum implementation, then run the full slice gate.

**Goal:** Complete the normalized Motion and Behavior contracts, schema-aligned
TypeScript surfaces, Recipe/Motion authoring and normalization, and the Button
vertical Foundation fixture through N24.

**Architecture:** Contract authority is fixed before generated/reference types,
then consumed through one-way packages. Structural Recipe logic remains generic;
CSS declaration validation and normalization are separate capabilities; Motion
is a parallel artifact joined only by explicit Recipe and Slot identity.

**Tooling:** TypeScript NodeNext, JSON Schema 2020-12, Ajv, Vitest, pnpm
workspace project references.
