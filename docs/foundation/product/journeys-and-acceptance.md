# PRD02 · 처음부터 설치까지의 사용자 시나리오

상태: 전체 문서 기준선 검토안 · 목표 Foundation 1.0.0 · 2026-09-12

책임 역할: 제품 기획자. 이 문서의 설계는 아직 제품 구현·실행 검증 완료를 뜻하지 않는다.

## 첫 사용자가 완성하는 흐름

새 사용자는 브라우저 보관 또는 로컬 폴더 보관을 고른다. 기본 시스템과 컴포넌트 템플릿이 준비되어 있고 온보딩은 목적에 맞게 건너뛰거나 연습할 수 있다. 첫 제안은 “브랜드 색을 바꾸고 Card에 적용해 보기”다. 빈 JSON부터 시작하게 하지 않는다.

1. 시스템을 만든다. 토큰·alias·테마를 시각적으로 편집하고 최종 값과 사용처를 본다.
2. 컴포넌트를 만든다. Card의 콘텐츠 자리를 구성하고 variant, Web/Mobile 디자인을 편집한다. 선택 기능은 필요할 때 추가한다.
3. 실제 동작을 살핀다. Button의 키보드 입력, Card의 읽기 순서, Toast의 enter/exit와 공지를 시연한다.
4. 검증 화면을 만든다. 인스턴스를 배치하고 긴 문구·좁은 화면·큰 글자·테마 조합과 화면 이동을 확인한다.
5. 타깃과 전달 방식을 선택한다. 후보 코드의 검증 결과, 의존성, 미지원 항목을 확인한다.
6. 프로젝트를 연결한다. init/doctor의 파일·alias·provider 변경안을 적용하고 실제 페이지에서 실행한다.
7. 새 시스템 버전을 만든다. 소비 앱은 기존 버전을 유지하며 diff 검토 후 개별 업그레이드한다.

## 인수 시나리오

| ID | 출발 상태와 행동 | 성공으로 관찰할 결과 |
|---|---|---|
| J01 | 기본 DS 색을 바꾸고 Undo | 사용처 preview·출처 표시, 한 번에 복원 |
| J02 | plain Card에 body와 action slot 추가 | 허용 콘텐츠 검사, 중첩 버튼 충돌 진단 |
| J03 | AI에게 선택한 Button 모션 수정 요청 | 참조 범위와 patch 확인, 동일 command 경로 |
| J04 | React·RN 프로젝트에 init | 실제 파일·의존성·provider 진단과 실행 가능한 페이지 |
| J05 | 사용자 수정 코드에 새 출력 적용 | 3-way 비교, 충돌 보존, 선택 적용과 rollback |
| J06 | 준비 팩으로 네트워크 차단 후 재시작 | 편집·준비된 검사·출력·내부 AI 연결 시험 |
| J07 | 공유 토큰 수정과 오래된 AI patch 충돌 | 검토 필요 표시, 겹치는 변경 자동 덮어쓰기 없음 |
| J08 | 브라우저 근사 Mobile preview 확인 | 실제 RN/Swift/Android 증거와 상태가 구분됨 |

각 시나리오는 대상 revision·환경·관찰·실패 지점을 기록한다. 표는 현재 통과 기록이 아니다. 자동·수동 세부 요구는 [시험 시나리오](../annexes/scenarios-and-evidence.md)에서 연결한다.

## 실패가 작업을 끊지 않게 한다

오류 토큰은 원본과 함께 초안으로 연다. 누락 폰트는 대체 표시와 재연결을 제공한다. AI 구현 실패는 마지막 검증본을 유지하고 후보·진단을 별도로 보여 준다. 설치 권한이 없으면 소스 내보내기와 필요한 연결 안내로 이어진다. 수정 후 검증되지 않은 상태를 이전 초록색 결과로 표시하지 않는다.

오프라인 진입을 위해 모든 사용자에게 Host 설치를 강요하지 않는다. 브라우저에서 가능한 작업과 준비된 로컬 실행을 구분한다. Windows에서 Swift native 검증이 필요하면 macOS 실행 환경을 지정하고 결과가 오기 전까지 검증 대기로 남긴다.

## 이 흐름이 만드는 제품 경계

검증 화면은 DS를 시험하기 위한 데이터·상태 시뮬레이션과 프로토타입 이동을 제공한다. 화면의 가짜 데이터나 “다음 화면으로 이동”을 공통 컴포넌트의 비즈니스 로직으로 승격하지 않는다. 사용자가 만든 실행 예제 소스는 전달할 수 있지만 일반 CMS 운영은 후속 별도 도메인이다.

여정 변경은 관련 UX, 명령 권한, 전달·검증 문서를 함께 수정한다. 자가 사용 후 소수 목표 사용자가 처음부터 설치까지 수행하는 과정을 관찰해 문구와 조작의 막힘을 개선한다.

## 결정 추적과 변경 영향
