## Signature interaction and motion

Select an object in the library or canvas; its frame and Part are highlighted while the inspector resolves its actual source value, token relationship and affected context. Dragging and resizing preview in document coordinates, and pointer-centered zoom keeps that document point fixed. Editing a token connects its row, structured value and actual component usage. Transient changes enter one visible review strip and one atomic Undo after apply. Controls respond immediately; short 160ms state transitions clarify focus, selection and panel changes. Reduced motion removes nonessential transitions. No page-load choreography.

## Cross-surface system

The same neutral roles, focus treatment, button/input/select/section/tab primitives, density and error states serve Foundation tables, catalog browsing, canvas editing, review, export and the Axiom UI reference surface. Light/dark Studio themes are independent of edited project themes. Small web viewports switch between library, canvas and inspector; panels do not squeeze all three into unreadable columns.
