## Product Purpose

Axiom is a Design System Builder. Its work product is a coherent foundation and component library with shared meaning across Web and Mobile designs and React, React Native, SwiftUI and Compose output. Canvas scenes demonstrate and validate the system; arbitrary application business logic is outside the initial product boundary.

## Positioning

ADS source is authoritative. GUI, public commands and future agent integrations share validation, review, revision, impact, commit and Undo. A visual change must remain explainable as a source change and deliver user-owned code.

## Operating Context

The existing React/TypeScript app stores projects through the transactional IndexedDB adapter. This is a local browser workflow with source export and an independent filesystem delivery CLI. No hosted account, collaboration service or AI connection is currently configured. The Windows computer remains the work host.

The current owner request authorizes a complete editor-gap audit, catalog expansion, token creation/management/classification, individual selection editing, zoom/pan and expected design-editor operations, a replacement visual system, and Axiom's own reusable UI foundation. ## Brand Commitments

Name: Axiom Studio. The owner's latest 2026-09-14 direction combines a precise blueprint language with flat, translucent editor chrome. Geist Variable is the locally hosted primary face, SUIT supplies Korean glyphs, and Geist Mono carries code and measurements. The first-run appearance is dark; light and previously saved appearance choices remain supported. Fluorescent green (#8DFC52) is the action and dependency accent. Neutral shades are achromatic. New-project onboarding suggests Geist and #8DFC52; applying those suggestions to a new project remains separate from changing an existing project.

Use compact control heights (28/32/36px), optical corners (8px for small nested details, 12px for controls, 16px for larger surfaces), and 4/8/12/16px spacing. Circular canvas tools retain a circular silhouette. Panels use neutral translucent fills and backdrop blur without inset highlights or bevels. Contextual tooltips, restrained scroll indicators and an adjustable navigation width support dense authoring without making the chrome dominate the materials.

Foundation browsing must express each value's purpose. Domain navigation uses one blueprint drawing per domain, with visible boundaries between domains. Primitive scales and semantic roles have distinct hierarchy. Colors form compact square shade rows; spacing and sizing use aligned rulers; radius retains its corner specimen; borders become line samples; shadows sit on an open plane; typography uses the authored family, weight, size, leading and tracking. Dependency diagrams connect actual source references and selected-theme overrides, with optional motion that respects reduced motion. Domain family context may shorten a visible token name without changing source syntax.

Library previews communicate the component's recognizable structure. Curated catalog references and previews are separate from target runtime support; unavailable behavior or output must remain explicit. All editor surfaces retain Korean and English copy and preserve authored values, review boundaries and rejected form input.

## Product Principles

- Let people find, create and edit the object they intended without opening raw JSON.
- Make identity, inheritance and affected usage visible at the point of change.
- Keep authoring responsive while retaining the common reviewed transaction boundary.
- Make every shipped control perform its stated operation; show unsupported obligations explicitly.
- Preserve user work, original source and recoverability.

## Accessibility & Inclusion

Keyboard operation, visible focus, target-size and contrast requirements, reduced motion, Korean IME, English localization and clear error recovery are required by the Foundation. The editor is desktop-first; smaller web viewports must retain access to navigation, canvas and inspector without horizontal document overflow.
